# ASO Jumelo — App Store & Play Store

Métadonnées prêtes à coller dans **App Store Connect** et **Google Play Console**.  
Ce n’est **pas** du SEO web : l’indexation store repose sur nom, sous-titre / short description, mots-clés (Apple), description, catégories, notes et rétention.

> **Limite réaliste** : un bon ASO améliore la *découvrabilité* sur des requêtes pertinentes. Aucune garantie de classement #1.

## Proposition FR (synthèse)

| Champ | Valeur | Limite |
|-------|--------|--------|
| **Nom Apple / titre Play** | `Jumelo - Coéquipiers & Duo` | 30 |
| **Sous-titre Apple** | `Matching gaming & sport` | 30 |
| **Mots-clés Apple** | `binome,jumelage,duo,coop,jeux coop,sport coop,partenaire,equipe,matchmaking,multijoueur,esport,squad` | 100 |
| **Short desc Play** | `Trouve des coéquipiers et binômes pour jeux en coop, sport et activités.` | 80 |

**Pourquoi ce découpage**

- Le **nom** porte la marque + intention (`coéquipiers`, `duo`).
- Le **sous-titre** ajoute `matching`, `gaming`, `sport` sans répéter le nom.
- Les **keywords** Apple excluent les mots déjà dans nom/sous-titre (évite le gaspillage), sans espaces après les virgules.

Alternative plus « brand only » (meilleure conversion visuelle, moins de mots dans le titre) :

- Nom : `Jumelo`
- Sous-titre : `Coéquipiers gaming & sport`

## Hors scope (rappel)

- Pas de landing marketing dédiée dans ce repo → SEO web non traité ici.
- Identifiants (`app.jumelo`) inchangés.
- Les champs keywords Apple / textes longs se collent **manuellement** dans les consoles (EAS Submit ne remplace pas tout le listing).
